CÓMO PONERLO A FUNCIONAR

1) SUBIRLO A INTERNET
   No necesitas Netlify Y GitHub: con uno basta.
   - Netlify: entra a app.netlify.com/drop y arrastra una carpeta que tenga SOLO index.html. Listo.
   - GitHub (opcional): solo si quieres guardar el código o que Netlify se actualice solo.
   Los archivos .rules NO se suben a Netlify: se pegan en Firebase (paso 2).

2) NUBE Y CHAT (Firebase, gratis)
   La música y el código secreto funcionan solos. Las cuentas y el chat necesitan Firebase:
   a. console.firebase.google.com -> Crear proyecto.
   b. Compilación > Authentication > Comenzar > "Correo electrónico/contraseña" > Activar.
   c. Compilación > Firestore Database > Crear base de datos > pestaña "Reglas" >
      borra lo que hay, pega el contenido de firestore.rules > Publicar.
   d. Engranaje > Configuración del proyecto > Tus apps > icono </> (Web) > registrar app >
      copia los valores de firebaseConfig y pégalos en index.html donde dice PEGA_AQUI
      (apiKey, authDomain, projectId, storageBucket, appId).
   e. SOLO PARA VIDEOS: Compilación > Storage > Comenzar (pide el plan Blaze, que tiene
      cuota gratis) > pestaña "Reglas" > pega storage.rules > Publicar.
      Las fotos y todo lo demás funcionan sin Storage.

3) USO
   - Toca la esquina superior derecha de la pantalla de música (botón invisible).
   - La primera vez crea tu código (2 veces). Después ese código abre la pantalla secreta.
   - "Reiniciar aplicación" (abajo) borra música, código y sesión de ESE dispositivo.
   - El código de chat que compartes es tu número de 15 dígitos.
